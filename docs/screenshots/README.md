# Sidekicks screenshots

- `sidekicks-icon.png`: the Sidekicks pink mascot, with its dark background removed using imagegen; saved as a transparent PNG for the README.
- `sidekicks-web.png`: screenshot of our local Sidekicks website, captured October 5, 2026. Its product preview is illustrative.
- `sidekicks-iphone.png`: actual native iPhone welcome screen, captured from an isolated simulator on October 5, 2026.

The nine `sidekicks-mobile-*.png` images are native feature screens from an isolated demo host and simulator. See the [feature tour](../guides/mobile-feature-tour.md) for their scope and setup requirements. Messages and approvals were seeded; the routine is disabled. Widget and Live Activity previews use sample data. Capture-only navigation was confined to a temporary build.

No authenticated account, customer notes, or upstream launch video is used in the
Sidekicks README. Older `codync-macos-home.jpg` and `launch-film.jpg` are legacy
upstream assets retained for historical references; they are not Sidekicks screenshots.
