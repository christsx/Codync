# Sidekick terminology

User-facing Apple, Linux, and terminal labels call coding companions Sidekicks:
New Sidekick, Search sidekicks, Sidekick settings, and sidekick instructions.
Widgets and menu-bar descriptions use the same terminology. New unnamed
companions default to New Sidekick in the host source.

Existing companion names are preserved. Internal Bot types, protocol keys,
API methods, identifiers, and storage remain compatible.
