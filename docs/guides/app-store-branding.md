# App Store branding

The iOS listing uses **Sidekicks - AI Coding Agents** with the subtitle
**A little crew. A lot done.** The description explains choosing coding agents,
project conversations, account connections, and Cloud Workspace or computer runs.

The iOS app icon uses the pink furry flower mascot from the website's original
render (`web/public/sidekicks/pink-mascot-hd.png`). Its opaque 1024px asset is
`apps/ios/Resources/Assets.xcassets/AppIcon.appiconset/image.png`.
App Store Connect receives this icon from a newly uploaded iOS build;
editing website metadata does not change the App Store icon.

Build 29 contains this icon update. This is an iOS distribution branding change;
macOS, Linux, shared SwiftUI, and terminal UI behavior are unaffected.
